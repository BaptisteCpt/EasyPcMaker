# EasyPCMaker
 ## Contexte
Easy PC Maker est un projet qui se rapproche beaucoup d’un Config’O’Matic. Si vous ne savez pas ce que c’est,
il s’agit d’un outil permettant de concevoir un PC en choisissant les composants un à un. 
Sa particularité est qu’il ne propose que des composants compatibles entre eux.

Pour avoir un exemple concret, vous pouvez regarder celui de TopAchat : 
[ConfigoMatic - Ton PC sur mesure](https://www.topachat.com/configomatic).

 ## Objectif de développement
- Concevoir et créer une base de données
- Écrire des requêtes SQL dans l’optique d’utiliser les données sur le site
- Développer un site Web fonctionnel et dynamique
- Utiliser une API
    
 ## Langages utilisés
- HTML (Front)
- CSS (Front)
- JavaScript (Front et back)
